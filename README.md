# KarlHarnois/tap

Homebrew formulae for [Ringleader](https://github.com/KarlHarnois/ringleader).

```sh
brew install KarlHarnois/tap/ringleader
```

Each Ringleader release publishes itself here: Ringleader's release workflow sends the new tag, and `.github/workflows/release.yml` points the formula at it, builds the bottle, and commits.
